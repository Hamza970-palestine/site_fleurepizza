🍕 Présentation du projet

Ce projet consiste à développer un site web moderne pour la pizzeria familiale située à Écouis.

Le site aura pour objectif de digitaliser la carte actuelle, améliorer la visibilité locale et offrir une meilleure expérience client.
*------------------------------------------------------------------------------------*

🎯 Objectifs du projet
Objectifs principaux
Transformer une carte papier complexe en interface digitale claire
Permettre une navigation rapide par catégories :
Pizzas
Menus
Tacos / Burgers / Paninis
Mettre en avant les offres (ex : 2 achetées = 1 offerte)
Afficher les informations importantes :
téléphone (02.32.51.03.55)
horaires
livraison
